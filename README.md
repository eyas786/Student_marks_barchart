# ITPS Student Marks Analysis

A Python data analysis and visualization project built using **NumPy** and **Matplotlib**. This script analyzes student test scores across two exams, calculates averages, identifies passing students, and displays a bar chart of the results.

## Features
* **Array Inspection:** Displays shape, size, dimensions, and data types of the marks matrix.
* **Statistical Analysis:** Calculates individual student averages, test averages, highest scores, and lowest scores.
* **Filtering & Broadcasting:** Identifies students scoring an average of 60 or above and applies a +5 bonus mark calculation.
* **Data Visualization:** Generates a bar chart comparing average marks across all students.

## Requirements
Make sure you have Python installed along with the following libraries:
```bash
pip install numpy matplotlib
```

## How to Run
1. Clone or download this repository.
2. Open the project in PyCharm or your terminal.
3. Run the Python script:
```bash
python main.py
```
